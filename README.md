# TaskFlow SaaS Website

A responsive front-end SaaS website built with plain HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser. No server or build step is required.

## Included
- Responsive landing page
- Navigation and mobile menu
- Dark/light theme toggle with localStorage
- Hero section and dashboard preview
- Features
- How it works
- Pricing cards
- FAQ accordion
- Login modal with demo form
- Toast notifications
- Responsive mobile layout

## Note
This is a front-end demo. Real authentication, database, payments, APIs, and server-side security would need a backend.
